# O Mundo CLT

Jogo em desenvolvimento pela LVSR Games, feito no Godot 4.

## Versão atual

**Android Alpha v0.29.20**

- Projeto: `O_Mundo_CLT_Godot_v0.29.20.zip`
- APK gerado: `build/android/O_Mundo_CLT_Alpha_v0.29.20.apk`
- Fluxo inicial: abertura → menu principal → Novo Jogo → criação do personagem → contratação → expediente

O workflow da branch `main` valida os arquivos, cenas e scripts, executa o teste de abertura, gera o APK e publica o resultado como artefato. Depois de aprovado, o próprio workflow faz commit/push do APK na `main`.
